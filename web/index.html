Common questions

How do you decide if an episode is OK for kids?

Each episode is scored 1–5 for violence, sex and language from its transcript. The overall score is the highest of the three. 1–2 is all clear, 3 is a gray area worth previewing, and 4–5 is a hard pass for little kids.

Do you show what actually happens in the episode?

Yes. Every episode page lists each flagged theme, how many times it occurs, and the moments behind it — direct quotes, or a short description of the scene when there is no line to quote.

Where should I start if I just want something safe tonight?

Open What to watch — each show has a list of the safest episodes and the ones to skip, built from the same 1–5 scores.
